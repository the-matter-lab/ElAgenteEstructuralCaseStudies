# DFT refinement — Case 7, GPT-5.4 Run 1

B3LYP-D4/def2-SVP geometry optimizations and frequency calculations started from
the structures generated by the agent in `runs/gpt-5.4_max/repeat_1`. These are
**author-side calculations**, not calculations performed by the agent during the
autonomous trajectory. The original run is unchanged.

## Method

- PySCF 2.15, B3LYP (VWN5 form) with D4 dispersion (BJ damping), def2-SVP,
  density fitting with def2-universal-JKFIT, grid level 4.
- Optimizer: Sella (`order=0` for minima, `order=1` for transition states),
  `fmax = 0.01 eV/Å`.
- Harmonic thermochemistry at 298.15 K and 1 atm. D4 is included in the energy,
  the gradient and the Hessian.
- SO is treated as a triplet; a closed-shell singlet SO is included for reference.

## Results

Relative to the Path A reactant, in kcal/mol (`relative_energies.csv`):

| Species | Path | ΔE | ΔG |
| --- | --- | ---: | ---: |
| Reactant | A | 0.0 | 0.0 |
| Reactant | B | 12.8 | 13.1 |
| TS | A | 32.8 | 31.7 |
| TS | B | 29.3 | 27.9 |
| Pyrazole + triplet SO | A | −16.1 | −28.9 |
| Pyrazole + triplet SO | B | −16.0 | −29.5 |

Both transition states are first-order saddle points (imaginary frequencies
−435.2 cm⁻¹ for Path A and −403.1 cm⁻¹ for Path B).

## Files

- `job.py`: the script used for every species
  (`job.py NAME START.xyz SPIN ORDER NTHREADS`).
- `start_xtb/`: starting geometries, copied from the agent's Run 1 output
  (`structures/` and `calculations/`).
- `optimized/`: B3LYP-D4/def2-SVP optimized geometries.
- `logs/`: optimizer logs.
- `results/`: per-species JSON with E, H, G (Hartree), residual gradient and
  lowest frequencies.
